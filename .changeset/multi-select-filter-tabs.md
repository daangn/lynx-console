탭을 다중 선택 필터로 바꿨어요. 여러 탭을 동시에 켜서 합집합으로 보고, 아무것도 안 켜면 전부 보여줘요.

- 좌우 스와이프로 탭을 넘기던 구조를 없애고, 한 목록에 탭별 필터를 겹쳐 쓰는 방식으로 바꿨어요
- `Log`를 켰을 때만 레벨 드롭다운(`Filter ▼`)을 보여줘요
- 레벨 필터는 일반 로그에만 적용해서, 함께 선택한 Network·Perf 항목은 유지해요.
- `Network`만 단독으로 켜면 매치 순회가 되는 네트워크 전용 화면으로 바뀌어요
- 검색어를 통합 리스트와 네트워크 화면이 같이 써요. 검색이 네트워크 요청의 URL · 헤더 · 본문까지 훑고, 걸린 줄은 매치가 있는 섹션이 펼쳐진 채로 강조돼요
- 코드 실행 줄(`enter code...`)이 어떤 탭에서도 늘 보여요
- 네트워크 화면의 개수 표시를 통합 리스트와 같은 자리 · 같은 형식으로 맞췄어요
- 🗑 버튼이 로그 · 네트워크 · 성능 기록을 한 번에 지워요
- 통합 목록은 실제 모니터 수집 데이터를 사용해요. `console: false`여도 네트워크·성능 기록을 표시하고, 콘솔 출력 요약과 중복되지 않아요. 진행 중인 요청도 완료 상태로 갱신돼요.
